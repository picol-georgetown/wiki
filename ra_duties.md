# RA Duties

As an RA with Ethan, we'll largely work together on a joint research project. I'll also ask for your assistance with various administrative duties throughout the semester, primarily related to maintaining PICoL Lab. 
Please see below for more details about how to complete these duties.

* Request access for the [PICoL Admin Folder in the lab drive](https://drive.google.com/drive/folders/1thGPk4sOVHmCPm2Ck-4CK5Hqi1EEaW74?usp=sharing); you may need to request access for individual sheets below

## Start of Term Duties

* Update PICoL publication spreadsheet
    * [Link to PICoL Publication spreadsheet](https://docs.google.com/spreadsheets/d/1BARi6oll3NvhVh-Vx8GRS2n8hTG1G-eYhRsJyNljC94/edit?usp=sharing)
    * Contains: Papers relevant to the lab's topics written by lab members since PICoL was started (fall 2024)
    * Please update existing entries and add additional entries, including any lab-related publications from members that Ethan is a co-author on
* Update Ethan's publication spreadsheet
    * [Link to Ethan's Publication spreadsheet](https://docs.google.com/spreadsheets/d/1w9zQssIWZHGpq2vw0yDzQxrnchxEUbVbZLwaRMvhYhk/edit?usp=sharing)
    * Update publication information (e.g., new papers, archival version superseded by official version)
    * Fill in any missing information
* Update PICoL personnel spreadsheet
    * [Link to PICoL Personnel spreadsheet](https://docs.google.com/spreadsheets/d/1fJkFjEmw-u6k7XIUgKxp0M0IQGwZ6ppC9hxKl0-YkV0/edit?usp=sharing)
    * Update information based on year change, graduation, dead links, etc.
    * You can email lab members or lab list to obtain updated photos or personal information
* Update PICoL activities spreadsheet
    * [Link to PICoL Activity spreadsheet](https://docs.google.com/spreadsheets/d/1wiGjWRVU62ToGUsezNo9SSIK2MM5wBqxBQN0xDp_koc/edit?usp=sharing)
    * Add Bsky / Twitter announcements of papers or conference attendance; you can pull HTML directly from X and Bsky
* Use updated data to refresh the PICoL webpage
    * Once spreadsheets are updated, use the following code to regenerate and push the PICoL lab website; you'll need access to the PICoL github
    * Link to website generation code: https://github.com/picol-georgetown/picol-georgetown.github.io/blob/master/build_website.py
    * Push freshly-generated code; website will refresh automatically
* Update the PICoL Meeting Calendar
    * Move the previous semester's lab meeting calendar to `archive.md` page
    * Generate a template for a new lab meeting calendar that members can fill in to sign up for presentations

## Recurring Duties

* Run lab meeting communication (weekly)
  * If possible, please help Ethan in encouraging students to sign up for lab presentations and paper presentations
  * Obtain title and (short) abstract from the speaker a couple of days before their presentation
  * Send title and abstract out to the PICoL mailing list one day before the presentation
